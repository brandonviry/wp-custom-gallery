Prochaines étapes

1. Si ce test fonctionne mais pas dans WordPress, vérifiez :

  • Que le fichier frontend.css est bien chargé (F12 > Réseau > CSS)
  • Qu'il n'y a pas de conflit avec votre thème
  • Que le shortcode est bien [custom_gallery id="1"]

2. Si la sélection multiple ne fonctionne pas dans WordPress :

  • Videz le cache du navigateur (Ctrl + Shift + Delete)
  • Rechargez la page avec Ctrl + F5
  • Vérifiez la console JavaScript (F12 > Console) pour voir les erreurs
